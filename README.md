# csp-header-validator

> A tiny CLI that checks CSP headers for presence, syntax, and security score, emitting JSON/CSV reports for CI pipelines.

## Overview
Autonomous, lightweight, and utility-focused defensive cybersecurity auditing tool developed in Python.

## Installation
```bash
git clone https://github.com/4li466as/csp-header-validator.git
cd csp-header-validator
pip install -r requirements.txt
```

## Usage
```bash
python main.py --help
```

## Testing
```bash
pytest -v tests
```

This tool is developed strictly for defensive security, compliance verification, and authorized system auditing.
